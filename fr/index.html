02Ce que nous construisons

Ce que contient un produit que nous livrons.

L’essentiel du travail est invisible pour ceux qui utilisent le produit. Voici un produit type, couche par couche, et ce dont nous nous occupons à chaque niveau.

  1. L5

    Interface

    Applications web et mobiles rapides à charger et simples à utiliser. Design system, accessibilité et suivi des usages inclus.

    React · Next.js · Flutter · Figma

  2. L4

    Logique métier & API

    Vos règles métier en code propre et testé, avec des API documentées sur lesquelles d’autres équipes peuvent s’appuyer.

    Node.js · FastAPI · GraphQL · REST

  3. L3

    Couche IA

    Assistants, agents et automatisations avec garde-fous, évaluations et plafonds de coût, pour que les réponses restent ancrées dans vos données.

    LLMs · LangGraph · LlamaIndex · Evals

  4. L2

    Données

    Bases de données, pipelines et recherche vectorielle, modélisés pour que le produit grandisse sans refonte.

    PostgreSQL · Redis · pgvector · ETL

  5. L1

    Infrastructure & sécurité

    Configuration cloud, CI/CD, supervision, sauvegardes et contrôles de sécurité à chaque commit.

    AWS · Docker · Terraform · GitHub Actions

04Sous le capot

Comment un assistant IA répond à partir de vos documents.

C’est le système qu’on nous demande le plus souvent. Voici ce qui se passe entre une question et une réponse fiable.

  1. 01

    Ingestion

    PDF, Notion, Drive, tickets ou votre propre base de données.

  2. 02

    Découpage & vecteurs

    Les documents deviennent des passages, les passages deviennent des vecteurs.

  3. 03

    Indexation

    Stockés dans une base vectorielle, avec les mêmes droits d’accès que la source.

  4. 04

    Recherche

    Les passages les plus proches de la question sont remontés.

  5. 05

    Génération

    Le modèle rédige une réponse en s’appuyant uniquement sur ces passages.

  6. 06

    Contrôle & sources

    Des garde-fous vérifient la réponse et y joignent ses sources.

  1. Semaine 1

    Un appel de 15 minutes, puis un atelier sur les objectifs, les utilisateurs et les contraintes. Vous recevez une feuille de route écrite.

  2. Semaines 1 à 2

    Design & architecture

    Un prototype cliquable et la conception du système, validés avant d’écrire la moindre ligne de code de production.

  3. Semaines 3 à 7

    Développement

    Des sprints d’une semaine. À la fin de chacun, vous voyez une démo en direct d’un logiciel qui fonctionne.

  4. Semaines 5 à 8

    Tests & sécurité

    Des tests automatisés tournent à chaque modification, et une revue de sécurité clôt le développement.

  5. Semaine 8

    Lancement

    Mise en production avec supervision en place, et nous restons joignables les premiers jours.

  6. Après le lancement

    Suivi & évolution

    Nous continuons à faire évoluer le produit avec vous, ou nous vous le remettons avec une documentation complète.

08Carrières

Faites votre PFE chez nous.

Cinq stages de fin d’études (PFE), chacun sur un vrai produit. Un ingénieur expérimenté relit votre travail chaque jour, et l’objectif est de le livrer.

  • De vrais produits, de vrais utilisateurs
  • Revue de code quotidienne
  • Stack IA moderne : LLM, RAG, agents
  • Votre propre périmètre dès la première semaine

Stages ouverts

5 stages (PFE)

Projet: DocuMind

Vous construisez un assistant d’entreprise qui permet de discuter avec les documents de la société, avec des réponses qui citent toujours leurs sources. Vous êtes responsable de la stratégie de chunking, de la qualité de la recherche et des garde-fous contre les réponses hors sujet.

Python · FastAPI · LlamaIndex · Next.js · Vector DB

Postuler

Projet: RefactorBot

Vous construisez un agent qui refactorise comme un ingénieur senior : il lit du Python legacy, planifie la modification, écrit du TypeScript moderne et vérifie son propre travail avant qu’un humain ne le relise.

Python · LangGraph · React · Monaco · LLMs

Postuler

Projet: TubeMind

Vous construisez un producteur IA pour les créateurs de vidéos : à partir d’une seule niche, il explore les tendances, les analyse avec des LLM et rédige des plans de vidéos appuyés sur des données, le tout dans un seul workflow SaaS.

Next.js · TypeScript · Supabase · Tailwind · AI SDK

Postuler

Projet: HireStream

Vous construisez un assistant de présélection pour les recruteurs, qui prétraite les entretiens vidéo (clarté d’élocution, mots-clés, sentiment) afin qu’ils se concentrent d’abord sur les bons candidats.

Python · Whisper · MediaPipe · OpenCV · React

Postuler

Projet: Sentinel

Vous construisez le moteur d’un relecteur de code automatisé : des règles déterministes repèrent les secrets exposés, des LLM signalent les code smells, le tout avant la fusion d’une pull request.

Rust · Node.js · PostgreSQL · LLMs · CI/CD
