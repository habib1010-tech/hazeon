04Inside a build

How an AI assistant answers from your documents.

It's the system we get asked for most. Here is what happens between a question and an answer you can trust.

  1. 01

    Ingest

    PDFs, Notion, Drive, tickets or your own database.

  2. 02

    Split & embed

    Documents become passages, passages become vectors.

  3. 03

    Index

    Stored in a vector database, with the same access rules as the source.

  4. 04

    Retrieve

    The passages closest to the question are pulled back.

  5. 05

    Generate

    The model writes an answer using only those passages.

  6. 06

    Check & cite

    Guardrails check the answer and attach its sources.
